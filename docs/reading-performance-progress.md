## 三、验收约束

不能用暖缓存结果替代首次滚动，不能用长时间静止稀释随机跳转的慢帧。原文必须完整，链接、页面事件、选词和复制正常，关闭后清理所有自有绘制。记录原生绘制的视觉差异和标记补齐延迟，未通过的场景如实保留。

既有实现与历史数据见[阅读实现与验收](reading-progress.md)，本轮以最终实际构建的新测量为准。

## 四、体验取舍

生词先发现候选文字，再按视口与 1600px 预读区匹配和包装；跳转落点优先于文档顺序。持续滚轮期间暂缓生词和译文写入，停稳至少 100ms 后提交，因此首次进入区域可能短暂没有生词标记；已经出现的生词和译文保留，减少往返闪烁和页面高度变化。徽章统计已访问、预读区域的生词，不再提前扫描统计整页。

支持 CSS Custom Highlight 的浏览器直接绘制原文范围，词性分析在本机扩展后台执行，不发送正文到外部服务。保留链接、原 Text、选择和复制；生词仍保留原有交互和样式优先级。阅读优先时，对实际有阅读标记的生词仅登记一次基础视觉复位，原生范围负责文字绘制；首次滚动中复位可能尚未提交，短暂保留生词底色，停稳后统一完成。不支持原生高亮时继续使用既有 DOM 绘制，不能将新路径的性能结论扩展到回退路径。

原生高亮不支持渐变背景和字体粗细，荧光笔使用同色透明底，粗体与词首强调使用轻量文字阴影描粗。后台异常或单次请求超过 3 秒时暂用词首和规则强调，词性不保证补齐；正常后台的真实词性覆盖另行验收。动态隐藏、文字变更、移除内联子树和关闭扩展均需撤销失效范围及生词样式。

## 六、最终性能对照

以同机 Chrome、1280×900 视口、完整 Learn HTML/CSS 快照串行对照，开启 CET6、生词词后译文及全部阅读辅助。页面保持顶部 2 秒完成初始化，再跳到 73%／94% 后立即真实滚轮上下往返；每个落点都使用新文档，跳转前不滚动。新版两个落点各抽样 160 词，阅读与生词标记均为零；顶部始终为零，确认为未访问区。旧版已提前包装全页生词，但落点阅读标记仍为零。性能探针不在外层强制读取几何，鼠标在导航前定位，避免跳转与滚轮之间插入额外等待。
