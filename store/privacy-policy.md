# 生词高亮 隐私政策

生效日期：2026 年 10 月 1 日（适用于 3.0.0 及以后版本）

“生词高亮”（以下简称“本扩展”）是一个开源浏览器扩展，源码见 https://github.com/xqdd/highlight-new-words 。本扩展**没有开发者自己的服务器，不收集、不出售、不分享任何个人数据，也不做任何统计或广告追踪**。

## 一、本扩展在你的设备上处理哪些数据

- **网页文字**：内容脚本在你打开的网页中读取文字，与词书在本地比对后高亮单词。网页文字不会被保存，也不会离开你的设备。
- **你的设置和词表**：设置、熟词本、导入的词书、从有道/欧路同步下来的生词本，保存在浏览器的扩展本地存储（`storage.local`）中。
- **标签页网址**：工具栏图标上的生词数量按标签页保存在浏览器会话存储（`storage.session`）中，网址变化或关闭浏览器后清除；弹窗读取当前网址只用于显示站点名和按网站开关高亮。
- **凭据**：欧路 API token、WebDAV 账号密码只保存在本机。默认不参与跨设备同步，只有你逐项勾选“随同步上传”后才会随同步数据保存到你选择的同步位置。
- **发音**：发音使用浏览器或操作系统提供的语音合成功能，朗读的只是你点击的单词。某些浏览器自带的语音可能由浏览器厂商在线合成，这由浏览器决定，本扩展不接收这些数据。

## 二、只有在你主动开启时才会发生的网络请求

本扩展只在你开启对应功能后，直接从你的浏览器向下列服务发送请求，不经过任何中转服务器。安装后默认不连接任何云端生词本来源（有道、欧路都不会收到请求）。你在设置中打开某个来源后，扩展立即向它读取一次生词本，之后最多每天自动同步一次；有道只依靠浏览器里已有的有道登录 cookie。可随时在设置中关闭该来源。

| 功能 | 请求对象 | 发送的内容 | 用途 |
| --- | --- | --- | --- |
| 有道生词本来源 | 有道词典 `dict.youdao.com` | 浏览器自动携带的有道登录 cookie；删除或加回单词时附带该单词 | 读取你的有道生词本；按你的设置删除或加回单词 |
| 欧路生词本来源 | 欧路词典 `api.frdic.com`、`my.eudic.net`、`dict.eudic.net` | 你填写的欧路 API token 或浏览器自动携带的欧路登录 cookie；增删单词时附带该单词 | 读取你的欧路生词本和分组；按你的设置增删单词 |
| 真人发音（发音来源选有道或欧路真人发音时） | 有道词典 `dict.youdao.com` 或欧路词典 `api.frdic.com`（按你的选择） | 要朗读的单词（不带登录信息） | 下载该单词的真人发音音频 |
| WebDAV 同步 | 你自己填写的 WebDAV 服务器 | WebDAV 账号密码；同步数据（设置、熟词本、导入的词书，按你的选择可包含凭据） | 在你自己的服务器上备份和同步 |
| 浏览器账号同步 | 浏览器厂商的同步服务（如 Google 账号、Microsoft 账号） | 压缩后的同步数据（同上） | 在你登录同一浏览器账号的设备之间同步 |

这些服务如何处理数据，适用它们各自的隐私政策。你可以随时在扩展设置中关闭来源或同步；卸载扩展会删除本机保存的全部数据（浏览器账号同步区中的数据由浏览器管理）。

## 三、我们不做的事

- 不把网页内容、浏览记录或你的词表发给开发者或任何未列出的第三方；
- 不使用分析、统计、崩溃上报或广告 SDK；
- 不从网络加载或执行远程代码，内置词书和词典随扩展打包；
- 不出售或转让用户数据，不把数据用于与“高亮生词”无关的目的。

## 四、权限说明

每个浏览器权限的用途见扩展源码仓库中的 `store/permissions.md`。

## 五、变更与联系

隐私政策更新时会修改本页并更新生效日期；涉及数据处理方式的变化会在扩展更新说明中告知。问题与反馈请在 https://github.com/xqdd/highlight-new-words/issues 提交。
