# 商店文案（简体中文）

[TOC]

适用：Chrome 网上应用店、Microsoft Edge 加载项（Firefox 暂不上架）。字数限制与查证时间见 [docs/release.md](../docs/release.md)。

## 一、名称与简短描述（来自扩展包 manifest，两家商店共用）

名称和简短描述在扩展包的 `public/_locales/zh_CN/messages.json` 中（`appName`、`appDesc`），两家商店都从 manifest 读取，**在商店后台不能单独修改**，改了要重新打包上传。

| 字段 | 当前值 | 限制 | 状态 |
| --- | --- | --- | --- |
| 名称 `appName` | 生词高亮 - 有道/欧路生词本与分级词书 | Chrome ≤ 75 字符 | 20 字符，符合 |
| 简短描述 `appDesc` | 在英文网页中高亮有道/欧路生词本与四六级、考研、托福、雅思、GRE 等分级词书中的单词，支持行内翻译与词形还原 | Chrome ≤ 132 字符 | 55 字符，符合 |

## 二、详细描述 - Chrome 网上应用店

限制：纯文本，不支持 HTML/Markdown；Chrome 未公布硬性上限，保持在 16,000 字符内；禁止关键词堆砌。以下正文约 1,300 字符（2026-10-01 按当前构建核对功能），可直接粘贴。

```text
读英文网页和看 YouTube 视频时，把你需要学的单词自动标出来：鼠标悬停（手机上点按）即可看到音标、释义和词形，认识了一键标为熟词，以后不再高亮。

【选你要学的词】
· 内置分级词书：中考、高考、四级、六级、考研、专四、专八、雅思、托福、SAT、GRE；CEFR A2–C2 难度分级；COCA 词频分级。可组合启用，选 B2 就高亮 B2 及以上的词。
· 同步有道词典、欧路词典的云端生词本：每个生词本都是一本独立词书，各自同步、互不影响；欧路的“已掌握单词”可作为熟词本同步下来。
· 导入自己的单词表：TXT、CSV、TSV、有道导出 XML、欧路导出、Anki 导出文本。

【不打断阅读】
· 行内释义：在生词后或上方显示简短中文释义，可随时切换或关闭。
· 释义卡片：音标、发音、完整释义、考试标签，以及“过去式 / 原形 run”这样的词形说明。
· 卡片打开方式可选：鼠标悬停（可调延迟）、按住修饰键再悬停、点击；手机上点按。
· 词形还原：running、ran 都按 run 判断，标记熟词后同一单词的各种词形一起消失。
· 多种高亮样式：底色、马克笔、下划线、波浪线、点线、文字色等预设，可按词书分别配色，深色网页自动调整对比度。
· 代码块标注（默认关闭）：在技术文章的代码注释和字符串里也标出生词，在线编辑器和输入框不处理。

【YouTube 字幕】
· 字幕中的生词同样高亮，并在单词上方或词后显示简短释义；自动生成字幕只高亮。
· 按 Alt+L 暂停视频并打开“当前字幕面板”：整句放大显示，逐词查释义，可切换上一句、下一句或从此句继续播放。
· 可选：鼠标移到字幕上自动暂停，移开后继续。

【手机与触屏】
· 支持 Microsoft Edge for Android 等移动端，触屏下使用底部卡片。
· 屏幕边缘的悬浮球：查看本页生词并一键标为熟词、取词模式（点按任意单词查词）、快捷设置（行内释义、词书开关）、同步状态；在 YouTube 视频页点按悬浮球直接打开当前字幕面板。悬浮球可拖动，也可按网站隐藏。

【生词本、熟词本与同步】
· 在卡片上“加入生词本”：可写入本地生词本，或写入有道、欧路的云端生词本。
· 标记熟词时可选写入哪些熟词本、从哪些生词本中移除（本地或云端，默认只记在本地熟词本），10 分钟内可撤销。
· 熟词本支持导入导出。
· 设置、熟词本和导入的词书可以通过以下方式在设备间同步或备份，可同时启用：浏览器账号同步；WebDAV（坚果云、Nextcloud、群晖等自己的网盘）；手动导出备份文件，导入时可选合并或覆盖。欧路 token、WebDAV 密码等凭据默认不随同步上传。

【其他】
· 按网站开关高亮；工具栏图标显示本页生词数量，弹窗中查看本页生词与同步状态。
· 页面文字只在本地匹配，不上传任何服务器；本扩展没有开发者服务器，也不做统计。
· 界面为简体中文。

隐私政策：<隐私政策网址>
问题反馈：https://github.com/xqdd/highlight_new_words/issues
```
