# 商店文案（简体中文）

[TOC]

适用：Chrome 网上应用店、Microsoft Edge 加载项（Firefox 暂不上架）。字数限制与查证时间见 [docs/release.md](../docs/release.md)。

## 一、名称与简短描述（来自扩展包 manifest，两家商店共用）

名称和简短描述在扩展包的 `public/_locales/zh_CN/messages.json` 中（`appName`、`appDesc`），两家商店都从 manifest 读取，**在商店后台不能单独修改**，改了要重新打包上传。

| 字段 | 当前值 | 限制 | 状态 |
| --- | --- | --- | --- |
| 名称 `appName` | 生词高亮 - 有道/欧路生词本与分级词书 | Chrome ≤ 75 字符 | 20 字符，符合 |
| 简短描述 `appDesc` | 在英文网页中高亮有道/欧路生词本与四六级、考研、托福、雅思、GRE 等分级词书中的单词，支持行内翻译与词形还原 | Chrome ≤ 132 字符 | 55 字符，符合 |

## 二、详细描述 - Chrome 网上应用店

限制：纯文本，不支持 HTML/Markdown；Chrome 未公布硬性上限，保持在 16,000 字符内；禁止关键词堆砌。以下正文约 900 字符，可直接粘贴。

```text
读英文网页时，把你需要学的单词自动标出来：鼠标悬停（手机上点按）即可看到音标、释义和词形，认识了一键标为熟词，以后不再高亮。

【选你要学的词】
· 内置分级词书：中考、高考、四级、六级、考研、专四、专八、雅思、托福、SAT、GRE；CEFR A2–C2 难度分级；COCA 词频分级。可组合启用，选 B2 就高亮 B2 及以上的词。
· 同步有道词典、欧路词典的云端生词本，每个生词本都是一本独立词书，各自同步、互不影响。
· 导入自己的单词表：TXT、CSV、TSV、有道导出 XML、欧路导出、Anki 导出文本。

【不打断阅读】
· 行内释义：在生词后或上方显示简短中文释义，可随时切换或关闭。
· 释义卡片：音标、发音、完整释义、考试标签，以及“过去式 / 原形 run”这样的词形说明。
· 词形还原：running、ran 都按 run 判断，标记熟词后同一单词的各种词形一起消失。
· 多种高亮样式：底色、马克笔、下划线、波浪线、点线、文字色等预设，可按词书分别配色，深色网页自动调整对比度。

【熟词本与同步】
· 熟词本支持导入导出；可选在标记熟词时同步删除来源生词本中的同一单词（默认关闭）。
· 设置、熟词本和导入的词书可通过浏览器账号同步到其他设备。

【其他】
· 按网站开关高亮；工具栏图标显示本页生词数量。
· 支持 Microsoft Edge for Android 等移动端，触屏下使用底部卡片。
· 页面文字只在本地匹配，不上传任何服务器；本扩展没有开发者服务器，也不做统计。

隐私政策：<隐私政策网址>
问题反馈：https://github.com/xqdd/highlight_new_words/issues
```

## 三、详细描述 - Microsoft Edge 加载项

限制：250–10,000 字符，必须完整说明全部功能。Edge 的简短描述同样来自 manifest。正文沿用第二节，并在开头补一句适用说明：

```text
（与第二节正文相同，在第一段后追加一行）

```

## 四、Edge 搜索词

限制：最多 7 个词条，合计不超过 21 个词，每个不超过 30 字符；不对用户展示。
